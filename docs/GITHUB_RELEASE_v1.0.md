# 📅 WeekNumber 1.0

The first public release 🎉 — your current ISO week in the Windows tray or the
macOS menu bar, one click from a two-month calendar.

<img width="446" alt="WeekNumber 1.0 calendar in dark mode" src="https://raw.githubusercontent.com/Shanko100/ISOWeekNumber/main/docs/screenshots/windows_calendar_dark.png" />

## ✨ Highlights

- 🗓️ **Two-month calendar** with ISO-8601 weeks
- 🎉 **Public holidays** for up to two countries, offline
- 🌍 **Time-zone clock** picked from a world map
- 🎨 **Your own colour**, bold digits, light or dark mode
- 🔌 **No network unless you allow it** — asked every time
- 🪶 **Light** — only the tray loads at start-up
